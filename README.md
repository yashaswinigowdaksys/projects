# Data Science & Machine Learning Projects

A collection of data science, predictive modeling, and analytics projects covering customer retention, sales analysis, recommendation systems, and health data.

## 📁 Repository Contents

* **Churn_logistic_project.ipynb** – Customer churn prediction using Logistic Regression to identify key factors behind customer attrition.
* **Mobilephone_sales.ipynb** – Exploratory data analysis (EDA) and trends analysis on mobile phone sales data.
* **SVD_Netflix_project.ipynb** – Movie recommendation system built using Singular Value Decomposition (SVD) collaborative filtering.
* **assignment_covid19.ipynb** – Statistical analysis and visualization of COVID-19 dataset trends.
* **google_play.ipynb** – App store market analysis focusing on ratings, reviews, and category performance.
* **heart.ipynb** – Classification models to predict the presence of heart disease based on clinical features.
* **hotel.ipynb** – Analysis of hotel booking patterns, cancellation factors, and customer preferences.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
